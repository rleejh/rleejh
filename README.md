## Projects:

**[FlutzPanel](https://github.com/rleejh/flutzpanel)** is a full-stack figure skating scoring app. You build a program from jumps, spins and sequences, and it validates the configuration and calculates the running technical score.

- Java and Spring Boot backend with REST APIs, persisted in PostgreSQL through Spring Data JPA
- Rule-based scoring and validation logic, with JUnit tests for scoring calculations and invalid configurations
- React and TypeScript interface for adding and removing program elements and viewing the running technical total

**Tech:** Java, Spring Boot, PostgreSQL, React, TypeScript, JUnit

**Next:** editing elements in the UI, server-side validation, and more scoring tests.
